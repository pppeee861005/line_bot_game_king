# 遊戲王表管理系統 - Line Bot 版本

本專案為一款基於 Google Apps Script 的遊戲王表管理系統 Line Bot，主要用於追蹤遊戲中王的重生時間並提供查詢功能。

## 主要功能

1. 自動追蹤和更新王的重生時間
2. 支持通過名稱或關鍵字查詢王的狀態
3. 提供重生時間的自動計算和更新
4. 支持批量重置王的時間
5. 提供 Line Bot webhook 處理，只對特定指令回應
6. 包含錯誤處理和伺服器狀態檢測功能
7. 支持 `ping` / `測試` 指令檢查伺服器運行狀態

## 使用說明

1. 將 `line_bot_game_king.js` 部署至 Google Apps Script。
2. 在 Google 試算表中設定參數工作表 `參數設定`，包含 Line Bot 權杖、試算表 ID、工作表名稱等。
3. 設定王表資料，包含王名稱、重生間隔、上次出現時間等欄位。
4. 設定 Line Messaging API 的 webhook 指向 Google Apps Script 的 `doPost` 函數 URL。
5. 使用 Line 發送指令與 Bot 互動。

## 支援指令

- `出` 或 `顯`：顯示王表狀態
- `K [王名稱/編號/關鍵字] [時間]`：更新指定王的時間，時間格式為 HHMMSS（可選）
- `重置`：重置所有王的時間
- `ping` 或 `測試`：檢查伺服器狀態

## 開發與測試

- 可在 Google Apps Script 編輯器中執行 `testLineBot()` 函數進行功能測試。
- 伺服器狀態會回傳資料庫連接、Line API 連接及基本功能運作狀態。

## 注意事項

- 請確保 Line Bot 權杖與試算表 ID 設定正確。
- 王表資料格式需符合系統要求，避免資料異常。
- 本系統僅回應特定指令，其他訊息不會回覆。
